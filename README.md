# test-user-page

Vue 3 + Vite PWA (vue-router 4, Vuex 4, Vitest). Uses [Bun](https://bun.sh) as the package manager and script runner.

## Setup

```sh
bun install
```

## Commands

| Command | What it does |
| --- | --- |
| `bun run dev` | Start the Vite dev server with hot reload |
| `bun run build` | Production build (with service worker) into `dist/` |
| `bun run preview` | Serve the production build locally |
| `bun run test` | Run the unit tests with Vitest |
| `bun run lint` | Lint with ESLint |
| `bun audit` | Check dependencies for known vulnerabilities |
